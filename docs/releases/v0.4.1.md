# 🚀 v0.4.1 – Python 3.11 and PyPI

## Overview

`pctl` now installs on Python 3.11 and newer, is tested on 3.11 to 3.14, and is published to
PyPI. From this release `pip install pctl` works, so there is no need to clone the
repository. No command changes behaviour.

## Added

- **Install from PyPI** — `uv tool install pctl`, `pipx install pctl` or `pip install pctl`,
  and `pip install "pctl[fast,azure]"` for the optional extras. The from-source steps are
  unchanged.
- **Build and publish in CI** — a `build` job runs on every pull request and release. It
  builds the sdist and wheel, installs the wheel into a throwaway virtual environment and
  runs `pctl --version` and `pctl --help`. A `publish` job runs on a published release,
  after the version check and the build, and uploads to PyPI with Trusted Publishing, so no
  API token is stored.
- **Package metadata** — author, license file, classifiers for Python 3.11 to 3.14 and
  project links (repository, issues, wiki, releases) are now set. The source distribution
  contains only the package, the README, the license and `pyproject.toml`.

## Changed

- **Python floor lowered to 3.11** — `requires-python` is `>=3.11`, down from `>=3.14`.
- **CI matrix** — the test job runs on Python 3.11, 3.12, 3.13 and 3.14 for every pull
  request.

## Notes

- **First release published to PyPI.** The Trusted Publisher on PyPI and the `pypi` GitHub
  environment were set up by hand. They must keep matching `ci.yml` and the environment name
  `pypi`.
- **The publish job is unproven.** This is the first time it runs, so whether the upload
  succeeds is not confirmed until this release is published. The name `pctl` was free on
  PyPI when the Trusted Publisher was created; that is not re-checked here.
- **Not confirmed locally.** The wheel build and install, and the 3.11 to 3.14 test matrix,
  are checked by CI on the pull request, not by running them on a developer machine.
- **PyPI versions are immutable.** A version that has been published cannot be replaced, so
  a failed or wrong upload means a new version.
- No behaviour change to any command. In the source, only the five `except` clauses
  changed, to the parenthesised form that Python 3.11 accepts.
- Requires Python 3.11 or newer, down from 3.14 in v0.4.0.
