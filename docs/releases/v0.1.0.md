## Overview

The first release of `pctl`, one CLI for the platform's providers. Two cases ship today,
Microsoft Graph and AWS DynamoDB, behind a single **case → service → action** command line
where the source tree mirrors the commands.

## Added

- **`pctl azure`** — token acquisition with on-disk caching, tenant-wide group listing
  across paginated results, group resolution by display name in `exact`, `prefix` or
  `search` mode, members and owners, and a `raw` escape hatch onto any Graph path with
  auth, retries and pagination handled.
- **`pctl aws ddb`** — list and describe tables, and read items via scan (with parallel
  segments), query or get-item, accepting plain JSON for expression values.
- **Four output formats** — `table`, `json`, `ndjson` and `csv`. The streaming three keep
  memory flat regardless of result size. Data to stdout, diagnostics and summaries to
  stderr.
- **Scriptable exit codes** — 0 success, 1 generic, 2 usage or config, 3 auth, 4 not
  found, 5 upstream, 130 interrupted, 141 broken pipe.
- **Ergonomics** — unambiguous command prefixes, aliases (`az`, `graph`, `ddb`),
  `-c/--columns`, and shell completion for bash, zsh and fish.
- **CI** — ruff lint and format on pull requests and on `main`, the full test suite on
  pull requests, and version-checked release tagging. Three collected test tiers: `unit`
  for pure functions, `smoke` for the CLI surface, `e2e` for the real command path with
  only the provider boundary faked.

## Notes

- **Requires Python 3.14 or newer.**
- Secrets never reach argv. Client secrets come from the environment or AWS Secrets
  Manager via `--secret-id`, which names a secret rather than carrying one.
- Tokens are cached under `${XDG_CACHE_HOME:-~/.cache}/pctl/tokens`, `0600` inside a
  `0700` directory. Disable with `--no-token-cache` or `PCTL_NO_TOKEN_CACHE=1`.
- `pctl azure token --raw` prints a bearer token to stdout. Treat it as a secret.
- `--decode` shows JWT claims without verifying the signature. Inspection only, not an
  authorization decision.
- Graph application permissions needed: `Group.Read.All`, plus `User.Read.All` to resolve
  members.
- Install the `fast` extra for `uvloop` and HTTP/2, and `azure` for
  `DefaultAzureCredential` when you are not using a client secret.
